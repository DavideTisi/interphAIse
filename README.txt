interphAIse — referee structure explorer

Open index.html in an ordinary browser with JavaScript enabled.
No installation, login, API key, server or internet connection is required.
Choose LiNbF6, LiTaF6 or LiCaAlF6 to compare its two separately calculated contacts.
Drag to rotate; scroll to zoom; use Colour to distinguish coating and substrate.
Save XYZ exports exact archived geometry; Save PNG exports the visible panel.

The hosted edition and this offline file contain the same six interfaces.
evidence.json records the final-index and geometry hashes, values and limitations.
The complete 460-geometry catalogue can be rebuilt from the project repository with:
    python scripts/build_structure_viewer.py
The compact edition is rebuilt with:
    python scripts/build_referee_viewer.py --output runs/referee-site

All interfaces are formally polar, provisional model results. LiF is uncomputed.
Later sensitivity results did not enter the live LLM decisions.
Lithium transport and battery cycling were not evaluated.
